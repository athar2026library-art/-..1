# اختبار Gemini مباشرة على Android (تجريبي)

هذا الإعداد مخصص للبناء المحلي فقط. لا تضف المفتاح إلى Git أو إلى ملف داخل المستودع.

1. افتح ملف `local.properties` في جذر المشروع (وهو مستثنى من Git).
2. أضف سطرًا مستقلًا:

   `geminiApiKey=ضع_مفتاح_Gemini_هنا`

3. نفّذ مزامنة Gradle ثم ابنِ نسخة debug.
4. افتح التطبيق وجرّب المساعد مع اتصال إنترنت.

إذا لم يعمل الطلب، تحقق من صلاحية المفتاح، وتفعيل Gemini API/إتاحته للمشروع، وقيود الحصة المجانية. قد تختلف الإتاحة والحدود حسب الحساب والمنطقة.

**تنبيه:** المفتاح الذي يُمرّر إلى `BuildConfig` يصبح قابلًا للاستخراج من APK. هذا مسار تجريبي خاص، وليس إعدادًا مناسبًا لتطبيق منشور. ألغِ المفتاح وأصدر آخر إذا سبق مشاركته علنًا أو ظهر في سجل يمكن لغيرك الوصول إليه.
